# GTA Cape Town — showreel

Brief clips of the GTA Cape Town game (~/GameDev/gtact): traffic, the helicopter, the jet, and mainly flying
around the CBD and the Atlantic seaboard so the main parts of Cape Town read, plus the basic menu and map.
One showreel, hip-hop bed, every cut on the beat so it slaps.

Footage: `projects/games/capture/gtact.mjs` (deterministic stepped capture, 30 fps, 1920×1080) → `input/clips/`.
Music: `input/music.mp3` = Basketball Flow — SoulProdMusic (Pixabay library copy in assets/audio/music).

v2 (2026-11-11): re-shot on the updated build (mountain flora, Sea Point promenade, rebuilt airport) and
extended with traffic and a police chase. New clips: promenade, street, chase, lions-head, table-mountain,
back-table, airport.
