# Brief — golive-promo

The go-live promo for **Midnite Studio**. The whole video tells a story that
explains the product, paced to the song.

- **Music**: `assets/audio/curated/music/The_Iron_Aria.mp3`
- **Audio-visual syncing**: the edits should be synced to the respective section
  of the song as closely as possible, to ensure correct pacing.
- **Pacing**: adapt the video to the pacing of the song. There are various
  stages, and the whole video basically tells a story to explain the product.
- **Typewriter**: when headings are typed out, there should be a subtle keyboard
  typing sound.

---

## STAGE 1: Intro

- **Duration**: 00:00 – 00:13 approximately
- **Style**: background black, terminal and text white; also use some shimmer
  effects.
- **Transition (entry)**: fade in from black with a blinking white cursor, then
  start typing with white text in the centre of the screen, with just a terminal
  icon to the left of the text and the caret on the right.

Typewriter effect — typing and then erasing the following, only ever showing one
line at a time:

- AI
- Agents
- Skills
- Loops
- Swarms
- Harness
- AGI
- ... ASI ...
- .......
- It is hard...
- .. just trying to keep up!

## STAGE 2: Product Intro

- **Duration**: 00:14 – 00:29 approximately
- **Transition**: reveal the logo, then the "Midnite" wordmark, and then type out
  "Studio" — just like the pilot video project's reveal of the wordmark.
- **Style**: fade in a light theme, transitioning the background as if a slide
  replaced the dark background by transitioning horizontally, with a liquid /
  smoke-like effect.

| Text | Visual |
|---|---|
| Launch any agent | show one agent-CLI logo after another, in the same position, increasing the speed as you go to each successive one; then reveal all in a row with a cascading effect. Then the terminal video launching new agents. |
| Manage multiple git repos | fade in video — the git repos sidebar |
| Watch your swarm | the git graph, with vibrant activity and colours |
| Manage your forge | forge actions reveal → GitHub Actions, PR review & approval |
| Dockable Browser | browser clips |
| System Monitor | workspace optimiser clips |
| Knowledge graph | codebase knowledge graph |

## STAGE 3: Build-up of the song

- **Duration**: 00:30 – 00:45 approximately
- **Style**: fade in a primary gradient glow effect and a few abstract particles,
  transitioning the background as if a slide replaced the dark background by
  transitioning horizontally, with a liquid / smoke-like effect.
- **Video**: quick clips of the other app features not yet shown in the video.

- Text: "So much more"
- Cycle through: Multi-screen, AI Councils, Workflows, Video Editor

## STAGE 4: Agentic Harness

- **Duration**: 00:45.5 – 01:06 approximately
- **Style**: fade in a dark theme, transitioning the background as if a slide
  replaced the dark background by transitioning horizontally, with a liquid /
  smoke-like effect.

- **Embedded skills**: Developing, Reviewing, Brainstorming!
- **Convenient loops**: quickly flash, each in its own colour — Guard (green),
  Ideate (cyan), Develop (blue), Patrol (purple), Medic (red), Overhaul
  (orange); then "configure behaviour with a UI", then "custom override".
- **Custom graphs** — show one at a time, with the logo / video: custom agent
  swarms, accomplish real workflows, automate anything.
- **Companion**: customize personality, MCP for true assistance, voice comms like
  J.A.R.V.I.S.

## STAGE 5: Outro (after the dubstep drop)

- **Duration**: 01:06 approximately

- **Connect with** — show one at a time, with the logo: GitHub, GitLab,
  Bitbucket, Azure DevOps.
- "Start for free"
- Show the {logo} "Midnite" wordmark (and "Studio" typewriter effect again) when
  the last boom/swoosh happens.
- "Coming Soon"
